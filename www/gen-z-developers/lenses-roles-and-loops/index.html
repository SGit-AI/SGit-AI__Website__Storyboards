The panels

  1. 1. Lenses, roles and loops: It stops being magic when you see how it works. (cover; Lenses, roles and loops)
  2. 2. One idea, recursion, through five lenses. Teenager → Musician → Doctor → Football fan → Portuguese (spectrum; Lenses, roles and loops, A prompt is a lens)
  3. 3. The wrong lens. Priya says: “I've always been bad at maths.” The Guide says: “The analogy is the reason someone understands something.” (scene; Lenses, roles and loops, A prompt is a lens)
  4. 4. A role is a model with a description. (graph; Lenses, roles and loops, A role is a model with a description)
  5. 5. An agent is a loop with a goal. The Guide says: “Fundamentally the agent is simply a task: do this; then, are we done yet, or do we need to continue?” (scene; Lenses, roles and loops, An agent is a loop with a goal)
  6. 6. The loop, with one tool call. (graph; Lenses, roles and loops, Tools changed everything; Precisely)
  7. 7. What the next request carries. Your question → Model asks → Harness → All of it, resent → The answer (spectrum; Lenses, roles and loops, Tools changed everything)
  8. 8. From training only, to tools. Nov 2022 → Mar 2023 → Mid 2023 → Nov 2024 → 2026 (spectrum; Lenses, roles and loops, Tools changed everything)
  9. 9. It remembers nothing. Zara says: “So it doesn't remember what I said an hour ago?” The Guide says: “There is no memory.” (scene; Lenses, roles and loops, It remembers nothing)
  10. 10. Long chats are compressed. What one summary keeps: the chat 100%, its summary 1.7% (evidence; Lenses, roles and loops, Long chats are compressed)
  11. 11. The newsroom's answer. “The rules are restored, not remembered.” (Re-anchoring agent behaviour policies (newsroom)) (evidence; Lenses, roles and loops, Long chats are compressed)
  12. 12. Many focused threads, each with a name. (graph; Lenses, roles and loops, Many focused threads)
  13. 13. Where the memory is. “Nothing is remembered by the model between sessions. Everything is remembered by the files.” (Memory is not a spectator sport (newsroom)) (evidence; Lenses, roles and loops, Long chats are compressed)
  14. 14. Not magic: a lens, a role, a loop.. (punchline; Lenses, roles and loops, Why this matters)
