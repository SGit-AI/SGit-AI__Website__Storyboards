The panels

  1. 1. Everything is connected: A graph is a network of nodes and edges. Start anywhere. (cover; Everything is connected)
  2. 2. Not a diagram. Priya says: “A graph? Like a bar chart?” The Guide says: “nodes, and the edges that connect them” (scene; Everything is connected, A graph is not a diagram)
  3. 3. The whodunit: who broke the build?. (graph; Everything is connected, The whodunit)
  4. 4. Zara's first job, as a graph. (graph; Everything is connected, A map is a graph with positions)
  5. 5. When a graph becomes a map. The Guide says: “a map is a graph with positioning” (scene; Everything is connected, A map is a graph with positions)
  6. 6. The same nodes, now positioned: a Wardley map. (map; Everything is connected, A map is a graph with positions)
  7. 7. Groups of groups: the abstraction layers. (graph; Everything is connected, Graphs of graphs)
  8. 8. Fractal. “There is no top and no bottom. There is only the altitude you happen to be looking from, and how much definition you choose to load at it.” (Introduci (evidence; Everything is connected, Graphs of graphs)
  9. 9. Provenance is a graph. (graph; Everything is connected, How I see the world)
  10. 10. Why the edges matter. “A node connected to nothing is literally meaningless.” (The graphs books (newsroom)) (evidence; Everything is connected, Graphs of graphs)
  11. 11. Start anywhere. Zara says: “There's so much. Where do I even start?” The Guide says: “It does not matter where you start; it matters that you start.” (scene; Everything is connected, Start anywhere)
  12. 12. Everything is connected. Start anywhere.. (punchline; Everything is connected)
