Release history

One row per push to dev, newest first. The site is at v0.1.2; it draws every panel with api.storyboards.sgit.ai v0.1.0, pinned in admin/build/api.json.

VersionDateWhat changed, and why
v0.1.22026-10-20A Developers link in the bar to api.storyboards.sgit.ai, which is now the developer site: everything about the code lives there, and this site stays about what the storyboards are and do. The second brief, published in full: code immutability as an agent behaviour policy (ABP-SB-001), and the API site as the developer site. This repository's .claude/settings.json runs the API checkout's code immutability hook, so a session started here cannot change a published release beside it either. No storyboard changed. And a top-level Behaviour policy page (/abp/), generated from policies/abp.json: the agents, the layers of control, the grant, the mandate, nine rules with their barriers and enforcement, where each maps to, and the gaps. Two rules that were prose now have checks: the build refuses an imported storyboard whose bytes changed (ABP-SB-002), and CI refuses an edit to a brief already on dev (ABP-SB-006).
v0.1.12026-10-20CI no longer asks a branch to bump the version when its commit is already on dev; a branch pushed alongside dev failed the check with nothing new in it. No page content changed.
v0.1.02026-10-20The first release: the 16 storyboards of gen-z-developers.sgit.ai (commit e2a71808) and the 7 of pki.sgit.ai (commit ab6affc9) imported unchanged with their casts, drawn by api.storyboards.sgit.ai v0.1.0 from an immutable, hashed path; each storyboard as a page (deck, grid, script), JSON, a bundle for embedding, a markdown script, a semantic graph, a thumbnail and a link preview, with SVG, animated SVG, PNG and JPEG exported in the browser; the brief in full, three articles, catalogue.json and llms.txt.
