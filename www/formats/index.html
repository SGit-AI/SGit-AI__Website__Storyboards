The formats

Every storyboard comes in seven shapes, made from one JSON file. Where each one lives, at which address, and what makes it.

For a storyboard at https://storyboards.sgit.ai/<series>/<slug>/:

ShapeAddressWhat it is
The pageindex.htmlthe deck (one panel at a time, swipeable, full screen), the grid and the script, with notes and sources
JSONstoryboard.jsonthe storyboard, unchanged from the file its origin site wrote
Bundlebundle.jsonthe storyboard, its cast and the prop packs it needs, in one file: what an embed fetches
Markdownindex.mdthe script: every panel as text, who says what, in what pose and mood, the evidence and its source
Semantic graphgraph.jsonnodes (the storyboard, panels, characters, props, sources, settings) and the edges that carry the meaning (has_panel, next, features, says, quotes, shows, set_in)
Thumbnailthumb.jpgthe cover panel, 480 by 300
Link previewog.jpgthe cover panel, 1200 by 750
SVGa button on the pageany panel, as a standalone SVG that links the fonts from the kit's release
Animated SVGa button on the pagethe same, drawing itself when opened (CSS inside the file, no script)
PNG, JPEGbuttons on the pageany panel at 1600 by 1000, fonts embedded
Contact sheeta button on the pageevery panel on one SVG, four per row

For the whole site: catalogue.json lists every storyboard with the address of each shape and its embed snippet, and llms.txt is the same for an agent that reads prose. A series' cast is at <series>/cast.json.

What makes each one

The JSON is written by a person or an agent. The markdown and the graph are made at build by formats.js, the API's own file, fetched from the pinned release v0.1.0 and checked against its hash before it runs, so a reader's browser running the same file gets the same bytes. The pictures are drawn by export.js with the same seeds as the deck, so an exported panel is the panel on the screen. Only the thumbnail and the link preview are committed as images, because a page needs them before any code runs; the build refuses a storyboard whose images were drawn from older data. One storyboard, seven shapes has the reasons.
