The Lab

Lots of small experiments in drawing, moving and laying out storyboards: other kinds of character, a stage you can direct like a game, physics, a camera, a flowchart and a threat model that explain themselves, a game engine. Each one is a single page that keeps working as the kit moves on, and each says what it taught us under the thing itself. A thing that works is lifted into the kit as a new release; a thing that does not stays here with its lesson.

▶ Start with StageEvery experimentThe kit's API ↗
StandaloneOne HTML file each. The kit by its immutable path with integrity strings; any other library vendored under a versioned name (anime-3.2.2.min.js, dagre-1.1.4.min.js, kaplay-3001.0.19.js, matter-0.20.0.min.js). Nothing fetched from a third party.
ProgrammaticEvery picture drawn by code from data, with a seed, so it is the same picture twice. No image files, no image models.
HonestEach page ends with what it taught us: what worked, what did not, what to lift, what to try next. The status on the card is exploring, promising, parked or lifted.
Yours to add toA folder, a page and an experiment.json, following lab/README.md; the checker opens it in Chromium and refuses errors and third-party requests.
